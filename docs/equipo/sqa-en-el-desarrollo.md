# SQA aplicado al desarrollo de QAlly

**No confundir con el catálogo de actividades que QAlly ofrece a sus usuarios.**

## Propósito
El enunciado académico requiere desarrollar la herramienta **y** evidenciar prácticas SQA utilizadas para crearla. El enunciado original `SQA26_Enunciado de Trabajo.pdf` es la autoridad para detalles de entrega.

## Actividades consideradas para el proceso interno del equipo
- Especificación de requerimientos (SRS) y diseño (SDS).
- Revisión de cambios mediante Pull Requests y revisión por pares.
- Convenciones de código, análisis estático, casos de prueba manuales, pruebas unitarias de lógica crítica.
- Definition of Done, trazabilidad CU ↔ RF ↔ pruebas, bitácora de calidad.
- Defectos del **desarrollo de QAlly** documentados mediante GitHub Issues.
- GitHub Actions para CI ligera es parte del stack aprobado; los checks concretos y su implementación aún deben definirse.

## Métricas consideradas para seguimiento interno (diferentes del catálogo del producto)
Tasa de pruebas aprobadas, porcentaje de PR revisados, porcentaje de DoD cumplido, cobertura de requisitos y porcentaje de actividades SQA con evidencia válida. Son ideas de seguimiento del proceso del equipo, no una decisión para incorporarlas automáticamente al catálogo de QAlly.
